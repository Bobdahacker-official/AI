# GenericCoding

Original prompt-and-solution code examples for commercial development tools, organized by `Mixed`, `Python`, `C++`, `C`, `Assembly`, `HTML`, `CSS`, `JS`, `RUST`, `PHP`, and `TYPESCRIPT`.

Each language directory contains 200 JSONL examples; `Mixed` contains 400 examples balanced across the listed languages. Every directory has train, validation, and test files in an 80/10/10 split plus metadata. Assembly examples use NASM x86-64 syntax. The records use only self-authored code and prompts and are CC0-1.0.
