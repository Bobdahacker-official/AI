# AI

This repository contains [Astheral](ASTHERAL.md), a 419,496,960-parameter assistant originally initialized from random weights, and [Generic/](Generic/), the separate GenericDataset collections.

Astheral is continuing from its own saved checkpoint using published human-preferred answers from an Anthropic 52B teacher. See [the teacher and training notes](TEACHER.md) for provenance, commands, and measured limitations.
