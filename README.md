# AI

This repository contains [Astheral](ASTHERAL.md), a 419,496,960-parameter assistant originally initialized from random weights, and [Generic/](Generic/), the separate GenericDataset collections.

Astheral continues from its own saved weights. Its training history includes published, human-preferred Anthropic 52B answers and focused synthetic conversation lessons authored in this session. See [Astheral's current training and evaluation notes](ASTHERAL.md) and [teacher provenance](TEACHER.md).
