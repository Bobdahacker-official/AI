# GenericConversations

Original, bounded helpful-assistant dialogues for commercial conversational products. Every record has six alternating user and assistant messages and labels its topic and interaction skills. The topics cover planning, explanation, troubleshooting, writing, decision-making, and habit building.

`Minimal` contains 60 records, `Balanced` contains 300, and `Big` contains 1,200. Every edition provides 80/10/10 train, validation, and test JSONL splits. All records are original local work and CC0-1.0.
