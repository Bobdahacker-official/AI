# GenericInfo

Original question-and-answer examples for commercial information and assistant products. They cover arithmetic, measurement, basic logic, computing concepts, and everyday science. Answers state the reasoning, not just a result, and each record supplies topic keywords and a difficulty label.

`Minimal` contains 60 records, `Balanced` contains 300, and `Big` contains 1,200. Each edition provides 80/10/10 train, validation, and test JSONL splits. All records are original local work and CC0-1.0.
