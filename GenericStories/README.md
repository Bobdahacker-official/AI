# GenericStories

Original short fiction for commercial narrative modeling and reading-comprehension products. Each JSONL record includes a complete three-paragraph story, title, genre, themes, reading level, and word count.

`Minimal` contains 60 records, `Balanced` contains 300, and `Big` contains 1,200. Each edition is independently generated from self-authored components and split 80/10/10 into train, validation, and test files. All records are original local work and CC0-1.0.
